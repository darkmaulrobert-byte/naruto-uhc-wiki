# ▸ Jinchûriki des Six Chemins

{% hint style="info" icon="circle-half-stroke" %}

<p align="center"><mark style="color:$success;"><strong>»</strong></mark> <strong>RITUEL</strong> <mark style="color:$success;"><strong>«</strong></mark></p>

➜ <mark style="color:$success;">**Conditions**</mark> • `/ns jubi`

> Il faut posséder **6 Bijû différents**, actifs ou en objet. Seuls ces joueurs peuvent faire le rituel :
>
> * [<mark style="color:orange;">**Madara**</mark>](../../roles/solos/madara.md) avec le **pacte 1** ;
> * [<mark style="color:orange;">**Madara**</mark>](../../roles/solos/madara.md) ou [<mark style="color:red;">**Obito**</mark>](../../roles/akatsuki/obito.md) avec le **pacte 2** : ils réunissent les Bijû **ensemble**, et celui qui lance la commande devient le Jinchûriki ;
> * [<mark style="color:orange;">**Kaguya**</mark>](../../roles/solos/kaguya.md).
>
> ⚠ [<mark style="color:red;">**Obito**</mark>](../../roles/akatsuki/obito.md) resté dans l'Akatsuki ne peut pas faire le rituel. Il n'y a qu'**un seul** Jinchûriki à la fois.

➜ <mark style="color:$success;">**Déroulement**</mark> • `Particularités`

> Le Gedō Mazō sort de terre devant le joueur.
>
> Les six Bijû quittent son inventaire et tournent autour de lui, de plus en plus vite, au milieu d'explosions.
>
> La statue les absorbe, puis l'objet de Jûbi rejoint le joueur. Le cri de Jûbi retentit sur toute la carte.
>
> ⚠ Les six Bijû sont **consommés**.

{% endhint %}

{% hint style="info" icon="circle-half-stroke" %}

<p align="center"><mark style="color:$success;"><strong>»</strong></mark> <strong>COMPÉTENCES</strong> <mark style="color:$success;"><strong>«</strong></mark></p>

➜ <mark style="color:$success;">**Pouvoir des Six Chemins**</mark> • `Passif`

> * <mark style="color:cyan;">**Vitesse II**</mark>.
> * <mark style="color:red;">**Force I**</mark>, s'il n'avait aucune <mark style="color:red;">Force</mark>.
> * Il **garde tous les pouvoirs** de son rôle.

➜ <mark style="color:$success;">**Saut de Jûbi**</mark> • `/ns jubi jump`

> Active ou désactive <mark style="color:$success;">**Sauts améliorés IV**</mark>.

➜ <mark style="color:$success;">**Gudōdama — Orbes de Vérité**</mark> • `Passif`

> Six orbes noires tournent autour du buste du Jinchûriki.
>
> Toutes les **5 secondes**, une orbe vise l'ennemi le plus proche à moins de **20 blocs**, avec l'un de ces effets :
>
> * une explosion de **1,5**<mark style="color:red;">**❤**</mark> ;
> * il ne peut plus sauter pendant **2 secondes** ;
> * il brûle pendant **3 secondes**.
>
> ⚠ Le partenaire du pacte n'est jamais visé.

{% endhint %}

{% hint style="info" icon="circle-half-stroke" %}

<p align="center"><mark style="color:$success;"><strong>»</strong></mark> <strong>CAPACITÉS</strong> <mark style="color:$success;"><strong>«</strong></mark></p>

➜ <mark style="color:$success;">**Épée de Nunoboko**</mark> • `Passif`

> Une épée en diamant **Tranchant IV**. Chaque coup a **25 %** de chances d'infliger **1**<mark style="color:red;">**❤**</mark> de plus et de repousser de **5 blocs**.

➜ <mark style="color:$success;">**Parer**</mark> • `Clic-Droit` avec Nunoboko • ⌚ : 5 minutes

> Après **2 secondes** de préparation, une brèche s'ouvre devant lui :
>
> * **30 blocs** de long, **8** de large, **10** de profondeur ;
> * **2**<mark style="color:red;">**❤**</mark> aux joueurs touchés.

{% endhint %}

{% hint style="info" icon="moon" %}

<p align="center"><mark style="color:$success;"><strong>»</strong></mark> <strong>RETOUR DE LA DÉESSE</strong> <mark style="color:$success;"><strong>«</strong></mark></p>

➜ <mark style="color:$success;">**Absorption par Kaguya**</mark> • `Clic-Droit` sur le cadavre

> Quand un autre joueur devient Jinchûriki, une flèche le montre à [<mark style="color:orange;">**Kaguya**</mark>](../../roles/solos/kaguya.md) pendant **2 minutes**.
>
> Si elle le tue elle-même, elle fait `Clic-Droit` **10 secondes** sur son cadavre, sans être touchée, pour absorber Jûbi. Elle garde tous ses pouvoirs.

{% endhint %}
