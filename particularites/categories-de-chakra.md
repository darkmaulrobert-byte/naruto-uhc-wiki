# ▸ Catégories de chakra

<h3 align="center"><mark style="color:$success;"><strong>»</strong></mark> Présentation <mark style="color:$success;"><strong>«</strong></mark></h3>

> Avec `/ns chakra <joueur>`, [<mark style="color:green;">**Kiba**</mark>](../roles/shinobi/kiba.md) découvre la **catégorie de chakra** d'un joueur. Elle ne donne ni le rôle, ni le camp.
>
> Chaque rôle a **toujours la même catégorie**. Ces catégories n'ont rien à voir avec les [natures de chakra](natures-de-chakra.md).

{% hint style="info" icon="dog" %}

➜ <mark style="color:green;">**Chakra apaisé**</mark> • `14 rôles`

> Principalement des Shinobi, mais certains ennemis peuvent aussi en faire partie.
>
> * Shinobi : [<mark style="color:green;">**Naruto**</mark>](../roles/shinobi/naruto.md), [<mark style="color:green;">**Sakura**</mark>](../roles/shinobi/sakura.md), [<mark style="color:green;">**Kakashi**</mark>](../roles/shinobi/kakashi.md), [<mark style="color:green;">**Hinata**</mark>](../roles/shinobi/hinata.md), [<mark style="color:green;">**Shikamaru**</mark>](../roles/shinobi/shikamaru.md), [<mark style="color:green;">**Chôji**</mark>](../roles/shinobi/choji.md), [<mark style="color:green;">**Kiba**</mark>](../roles/shinobi/kiba.md), [<mark style="color:green;">**Rock Lee**</mark>](../roles/shinobi/rocklee.md), [<mark style="color:green;">**Gaï**</mark>](../roles/shinobi/gai.md), [<mark style="color:green;">**Jiraya**</mark>](../roles/shinobi/jiraya.md), [<mark style="color:green;">**Tsunade**</mark>](../roles/shinobi/tsunade.md), [<mark style="color:green;">**Hiruzen**</mark>](../roles/shinobi/hiruzen.md), [<mark style="color:green;">**Minato**</mark>](../roles/shinobi/minato.md).
> * Akatsuki : [<mark style="color:red;">**Konan**</mark>](../roles/akatsuki/konan.md).

{% endhint %}

{% hint style="info" icon="dog" %}

➜ <mark style="color:yellow;">**Chakra trouble**</mark> • `7 rôles`

> Un mélange de Shinobi et d'ennemis : cette information ne suffit pas pour faire confiance au joueur.
>
> * Shinobi : [<mark style="color:green;">**Killer Bee**</mark>](../roles/shinobi/killerbee.md), [<mark style="color:green;">**Mei**</mark>](../roles/shinobi/mei.md), [<mark style="color:green;">**Ônoki**</mark>](../roles/shinobi/onoki.md), [<mark style="color:green;">**Quatrième Raikage**</mark>](../roles/shinobi/raikage.md).
> * Akatsuki : [<mark style="color:red;">**Nagato**</mark>](../roles/akatsuki/nagato.md), [<mark style="color:red;">**Itachi**</mark>](../roles/akatsuki/itachi.md).
> * Réincarnés : [<mark style="color:blue;">**Haku**</mark>](../roles/reincarnes/haku.md).

{% endhint %}

{% hint style="info" icon="dog" %}

➜ <mark style="color:orange;">**Chakra sombre**</mark> • `10 rôles`

> Principalement des ennemis, avec quelques Shinobi.
>
> * Shinobi : [<mark style="color:green;">**Gaara**</mark>](../roles/shinobi/gaara.md).
> * Akatsuki : [<mark style="color:red;">**Kisame**</mark>](../roles/akatsuki/kisame.md), [<mark style="color:red;">**Deidara**</mark>](../roles/akatsuki/deidara.md), [<mark style="color:red;">**Sasori**</mark>](../roles/akatsuki/sasori.md), [<mark style="color:red;">**Kakuzu**</mark>](../roles/akatsuki/kakuzu.md), [<mark style="color:red;">**Zetsu**</mark>](../roles/akatsuki/zetsu.md), [<mark style="color:red;">**Jûzô**</mark>](../roles/akatsuki/juzo.md).
> * Réincarnés : [<mark style="color:blue;">**Zabuza**</mark>](../roles/reincarnes/zabuza.md), [<mark style="color:blue;">**Mû**</mark>](../roles/reincarnes/mu.md), [<mark style="color:blue;">**Troisième Raikage**</mark>](../roles/reincarnes/raikage3.md).

{% endhint %}

{% hint style="info" icon="dog" %}

➜ <mark style="color:red;">**Chakra malveillant**</mark> • `6 rôles`

> Uniquement des ennemis : le joueur n'appartient pas au camp Shinobi.
>
> * Akatsuki : [<mark style="color:red;">**Hidan**</mark>](../roles/akatsuki/hidan.md), [<mark style="color:red;">**Obito**</mark>](../roles/akatsuki/obito.md).
> * Réincarnés : [<mark style="color:blue;">**Kabuto**</mark>](../roles/reincarnes/kabuto.md).
> * Solos : [<mark style="color:orange;">**Madara**</mark>](../roles/solos/madara.md), [<mark style="color:orange;">**Sasuke**</mark>](../roles/solos/sasuke.md), [<mark style="color:orange;">**Kaguya**</mark>](../roles/solos/kaguya.md).

{% endhint %}
