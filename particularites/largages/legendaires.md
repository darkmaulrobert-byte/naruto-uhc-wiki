# ▸ Légendaires

> Les caisses <mark style="color:yellow;">**Légendaires**</mark> donnent un **Largage légendaire**.
>
> `Clic-Droit` avec l'objet : un menu s'ouvre, et le joueur choisit **un bonus permanent**.

<table data-view="cards"><thead><tr><th align="center"></th></tr></thead><tbody><tr><td align="center"><p><mark style="color:red;"><strong>+10 % de Force</strong></mark></p></td></tr><tr><td align="center"><p><mark style="color:blue;"><strong>+10 % de Résistance</strong></mark></p></td></tr><tr><td align="center"><p><mark style="color:cyan;"><strong>+10 % de Vitesse</strong></mark></p></td></tr><tr><td align="center"><p><mark style="color:yellow;"><strong>+½ cœur maximal par kill</strong></mark></p><p>Pour chaque kill réalisé après l'obtention du bonus.</p></td></tr><tr><td align="center"><p><mark style="color:yellow;"><strong>−20 % sur les cooldowns</strong></mark></p></td></tr></tbody></table>

{% hint style="warning" %}

* Chaque bonus n'existe **qu'une fois par partie** : un bonus déjà pris apparaît comme **indisponible**.
* Un joueur ne peut obtenir **qu'un seul** bonus légendaire.
{% endhint %}
